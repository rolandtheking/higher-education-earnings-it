# Динамика заработной платы специалистов с высшим образованием в условиях деактуализации навыков в IT-индустрии

Репозиторий содержит воспроизводимый эконометрический код для исследования отдачи от высшего образования и штрафов за деактуализацию навыков на микроданных РМЭЗ-НИУ ВШЭ (2016–2025 гг.).

**Авторы:** Ильясов Р., Максимкина В., Пупышев В., Коротчик Я., Григорьев А.  
*Факультет вычислительной математики и кибернетики (ВМК МГУ / ВШЭ)*

---

## 📌 Структура проекта

* `data/` — Папка для размещения первичных микроданных РМЭЗ (не публикуются в репозитории).
* `src/` — Исходный код обработки и эконометрического оценивания:
  * `data_loader.py` — Загрузка даннных и объединение их в единый пул.
  * `feature_engineering.py` — Подготовка данных к дальнейшему исследованию (фильтрация, стратификация, вычисление производных признаков).
  * `models.py` — Спецификации Pooled OLS и Panel FE.
  * `visualization.py` — Построение визуаальной компоненты (графики).
* `notebooks/`
  * `research.ipynb` — Итоговый Jupyter Notebook с анализом, а также выводом регрессионных таблиц и визуализацией.
* `requirements.txt` — Зависимости проекта.
* `.gitignore`
* `Readme.md` — Этот файл.
